# Рабочая карточка: подтверждённая форма траектории участка

Цель: вместо движения между узлами по прямой показывать фактическую ломаную через измеренные промежуточные точки, одинаковую в редактируемом плане, 2D, 3D и экспортном кадре. События, времена и финансы остаются функцией независимо подтверждённых длин, спроса и календаря.

Связь: `docs/PRODUCT.md`, топология/просмотр, `docs/adr/0003-attested-facility-graph.md`, `docs/WORK_CARD_FLOOR_PLAN.md`, три типа объекта. Ветка `checkpoint/2026-09-27-full-work`, базовый SHA `2ae9c29`.

Scope IN: текстовые координаты поворотных точек одного этажа с обязательным источником и проверкой длины, геометрия в графе и версии ревизии, направление поездки туда/обратно, позиция внутри кривой по времени события, 2D/3D/PDF/SVG, legacy fallback. Scope OUT: навигация по произвольному пространству, детектор препятствий, расчёт clearance и реальная кинематика поворотов; не менять исходную длину или формулу времени.

Инварианты: существующая длина участка остаётся независимым подтверждённым input. Геометрия без измеренных крайних точек и без явного источника не считается подтверждённой. Изменение координат крайних точек снимает устаревшую ломаную только в новой ревизии. Данные старого прогона и денежный расчёт не пересчитываются. Длина по ломаной не может превосходить независимо измеренную длину участка больше допустимой погрешности ввода.

Acceptance: через интерфейс можно ввести, отредактировать и удалить промежуточные точки; неверные/дублирующиеся/межэтажные/несогласованные данные отклоняются, пользовательский источник сохраняется. Прямая часть старых схем остаётся; новые 2D, WebGL2, SVG/PDF следуют ломаной; обратный путь проходит те же точки в обратном порядке; длительности событий и KPI остаются прежними. Проверить v2/v3, склад/аэропорт/медучреждение, импорт планов с/без привязки, архивный прогон, JS/Django/браузер и экспорт.

Риски: линейная интерполяция между контрольными точками остаётся геометрическим приближением; нет доказательства наличия свободного габарита и совместимости робота с поворотом. Проверка длины позволяет измеренному пути быть длиннее ломаной — такой остаток не распределяется физически и должен остаться явным допущением.
