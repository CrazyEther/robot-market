# Развёртывание первой версии

## Локально

`docker compose up --build -d` запускает PostgreSQL и Django. Web и API обслуживаются одним процессом Django по порту 8000; это сознательная архитектура первого среза. БД хранится в отдельном Docker-томе. `/health` отвечает при работающем web; `/ready` требует реальной связи с БД и применённых миграций. При первом запуске выполняются `migrate` и `seed_demo`; seed не перезаписывает существующие строки.

## CI и внешний preview

GitHub Actions выполняет проверки и Docker build при PR/push. После успешной проверки `main` job `deploy` может вызвать URL деплой-хука, сохранённый в секрете GitHub `RENDER_DEPLOY_HOOK_URL`. Если секрет отсутствует, job только сообщает об отсутствии публикации.

В репозитории есть шаблон `render.yaml` для сервиса Django и отдельного PostgreSQL в Render. Его необходимо применить в принадлежащем владельцу аккаунте с предоставленными разрешениями и согласованным тарифом. В Render следует привязать **именно этот** репозиторий и ветку `main`, установить ограничения расходов, создать Blueprint и секрет деплой-хука в GitHub. Проверить, что preview отдаёт HTTPS и соответствует опубликованному SHA (`git rev-parse HEAD`); проверить `/health`, `/ready` и три демостраницы извне. Поле `autoDeploy: false` оставляет единственный trigger публикации после зелёных тестов CI.

На Render включено `ENFORCE_HTTPS=1`: Django перенаправляет HTTP на HTTPS за доверенным TLS-прокси и устанавливает краткосрочный HSTS. При локальном HTTP-тестировании и запуске Compose этот флаг не задаётся. Прежде чем использовать иной прокси, проверьте, что заголовок `X-Forwarded-Proto` устанавливается только доверенной инфраструктурой.

Пока провайдер не привязан и внешний адрес не проверен, онлайн-публикация имеет статус **blocked-by-access**. Конфигурация сама по себе не подтверждает существование работающего стенда. Для отката выбрать предыдущий проверенный commit/деплой в панели провайдера; перед изменением схемы БД проверить совместимость миграций. Закрытые исходные файлы и персональные данные не загружать в preview.
