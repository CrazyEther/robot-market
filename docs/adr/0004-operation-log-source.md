# ADR-0004: журнал поступления заданий как исходник событий

Дата: 2026-09-25. Статус: принят для контракта импорта T14–T16.

## Контекст

Пиковый поток в `workload_profile` описывает среднюю нагрузку часа и не задаёт времена отдельных заявок. Генерация равномерных или случайных поступлений из этого числа нарушила бы требование работать на наблюдённых данных объекта и скрыла бы очереди/пики.

## Решение

Владелец загружает UTF-8 CSV с колонками `requested_at,work_units`. Времена должны быть ISO 8601 с часовым поясом и идти по возрастанию. Каждая строка транспорта означает один рейс (`work_units=1`); уборка использует площадь задания в м². Дополнительные колонки не принимаются, поэтому идентификаторы пациентов, работников, багажных бирок и заказов не попадают в исходник. Пользователь подтверждает происхождение и отсутствие персональных данных.

Исходные байты, SHA-256, описание источника, номер строки, нормализованное время UTC, единица и версия парсера хранятся в `OperationLog`. Ревизия проекта закрепляет ссылку на конкретный журнал; смена операции снимает ссылку только в новой ревизии. Публикация исходного журнала через HTTP отсутствует.

Событийный движок должен читать именно закреплённые строки и выдавать воспроизводимый ledger. Наличие журнала не разрешает численный прогон без `fit` выбранной модели, измеренного маршрута, источников производительности, правил доступа и правил рабочего времени. Отдельная политика для зарядки, отказов, лифтов и конфликтных участков должна быть закреплена до публикации KPI, иначе они останутся непроверенными.

## Внешние сведения

- [AnyLogic Cloud custom UI](https://cloud.anylogic.com/custom-ui-demo/index.html#phase-1) показывает структуру выбора AGV, настройки, playback и эксперимента по парку/скорости. Это ориентир взаимодействия, не источник кода, результатов или лицензии.
- [Avinor: baggage process and data elements](https://xwiki.avinor.no/spaces/BARIN/pages/40173630/Baggage%2Bprocess%2Band%2Bdata%2Belements%2B-%2Bairport%2Bperspective) определяет bag events и временные отметки UTC. Документ не содержит журнал конкретного аэропорта.
- [FHIR SupplyDelivery](https://fhir.hl7.org/fhir/supplydelivery.html) допускает время фактической доставки, но также пациентские ссылки; этот медицинский ресурс не загружается напрямую в продукт.
