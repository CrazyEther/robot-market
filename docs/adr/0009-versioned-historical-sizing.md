# ADR-0009: версия расчёта парка для сохранённого прогона

Дата: 2026-09-27. Статус: реализован переход от версии 2 к версии 3; полная приёмка T17 требует эксплуатационных источников трёх объектов.

После уточнения физического паспорта багажной буксировки (ADR-0007) и больничной тележки (ADR-0008) новые численные расчёты по старому паспорту блокируются. Вместе с тем уже сохранённые `SimulationRun` содержат неизменяемый снимок входов и результат расчёта парка версии 2. Пересчёт такого прогона только по текущей версии отказал бы в повторном открытии исторического отчёта без изменения исходных файлов.

Новый расчёт парка имеет версию 3. Проверка сохранённого прогона берёт номер версии из его `input_snapshot.sizing`, воспроизводит именно эту версию и сравнивает полный результат со снимком. Неподдерживаемая версия или расхождение дают ошибку. Версия 2 доступна только внутри проверки исторического прогона; пользовательский новый расчёт, новый журнал спроса и новый денежный результат для прежнего паспорта аэропорта/больницы блокируются. Существующие отчёты можно просмотреть и скачать с явной отметкой о прежнем паспорте.

Это не подтверждает актуальную пригодность оборудования старой ревизии. Для решения о внедрении владелец заново сохраняет паспорт операции и выбирает модель по текущим критичным характеристикам. Изменения будущих алгоритмов требуют нового номера версии и сохранения воспроизведения старых веток.
