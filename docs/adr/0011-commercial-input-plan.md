# Денежный план из коммерческих условий

Пользователь может ввести коммерческие условия в форме либо загрузить подробный помесячный план. Форма сохраняет тот же проверяемый формат денежных строк и использует существующий алгоритм CAPEX, OPEX, TCO, ROI, NPV и окупаемости. Исторические планы не меняются.

Цена робота умножается на парк сохранённого проверенного прогона. Месячный объём равен выполненным рейсам за период, умноженным на явно введённое число повторений периода. Невыполненные задания не оплачиваются и не дают экономического эффекта. Повторения должны помещаться в 28 суток; сезонный календарь требует подробного плана. Пользователь подтверждает переносимость нагрузки и доступности на будущие месяцы. Этот прогноз не является гарантией будущей пропускной способности.

Для каждого сценария вводятся постоянные и переменные расходы с источниками. Подписка RaaS считается на одного робота; дополнительные расходы должны исключать включённые услуги. Все суммы обязательны, включая явные нули. Валюта, режим НДС, дата условий, ставка дисконтирования и источник прогноза сохраняются. Форма использует постоянные номинальные цены без индексации, налоговых корректировок и остаточной стоимости. Возвратный оборотный капитал покупки поступает обратно в последний месяц.

TCI определяется как сумма всех исходящих денежных потоков месяца 0, включая оборотный капитал. Это отдельное представление сохранённых строк, а не изменение формулы исторического CAPEX. CAPEX охватывает капитальные затраты всего горизонта. Статьи первоначальных затрат baseline и подключения RaaS выбираются пользователем по источнику: CAPEX, OPEX или прочий денежный поток. Суммы строк округляются один раз до четырёх десятичных знаков; прогнозный объём округляется вниз с той же точностью, чтобы не завышать выполненные работы. Все расчёты используют Decimal.
