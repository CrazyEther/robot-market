# ADR-0007: масса состава и тяговое усилие аэропортового тягача

Дата: 2026-09-27. Статус: реализован как консервативный контракт подбора; эксплуатационная приёмка ждёт данные аэропорта и подтверждение поставщика.

## Основание

Первичная [страница TLD EZTow](https://www.tld-group.com/technologies/eztow/) заявляет тяговое усилие 2000 daN. Оно нормализовано в закрытом дополнении производителя как 20000 N с сохранением исходных единиц и SHA-256 снимка. Это не грузоподъёмность платформы в кг и не автоматически допустимая масса конкретного состава. Старая форма багажной операции сравнивала `cargo_mass_kg` с `payload_kg`, что не доказывает пригодность тягача.

## Контракт

- Паспорт багажной буксировки версии 3 отдельно принимает измеренную массу всего буксируемого состава `towed_train_mass_kg` и рассчитанное для маршрута требуемое тяговое усилие `required_drawbar_pull_n`. Каждое значение требует источник владельца объекта. Второе число не выводится из первого без профиля уклонов, сопротивления качению, числа тележек и методики расчёта.
- Подбор отдельно сверяет массу с подтверждённым `tow_mass_kg` точной модели, усилие с `drawbar_pull_n`, ширину и качественные условия сцепки и допуска. Отсутствие любого критичного паспорта или входа даёт `requires_verification`; превышение подтверждённого предела даёт `reject`.
- Прежнее `cargo_mass_kg` не переименовывается в массу состава. Ревизии проекта неизменны; для нового расчёта владелец сохраняет новый паспорт и повторно выбирает модель. Расчёт парка не запускается по старой версии паспорта этой операции.
- Значение 2000 daN в источнике EZTow само по себе не даёт `fit`: у текущего пакета нет подтверждённой допустимой массы состава, конкретной сцепки и допуска аэропорта. Пакет не содержит коммерческую оферту.

## Открытый gate

Для численного прогона T15 нужны регламент аэродромных зон и буксировки, фактический состав/сцепка, измеренный маршрут, календарь, журнал заданий и денежный договор. События совместного движения и приоритеты на маршруте не предполагаются из паспортной страницы тягача.
